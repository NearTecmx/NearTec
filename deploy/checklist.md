# Checklist de despliegue

## Antes de subir

- [ ] Validar correos y teléfono oficiales.
- [ ] Confirmar si `info@neartec.com` o `info@itimbre.com` será correo principal.
- [ ] Revisar precios y notas de IVA.
- [ ] Confirmar claims legales/fiscales.
- [ ] Optimizar `assets/img/neartec-logo.jpg` si pesa demasiado.

## Subida

- [ ] Subir archivos al servidor.
- [ ] Probar `/`, `/landing-diagnostico.html`, `/robots.txt`, `/sitemap.xml`.
- [ ] Probar PDF en Chrome móvil y desktop.
- [ ] Probar WhatsApp.
- [ ] Probar CSV.
- [ ] Si se usará PHP, crear `api/config.php`.

## Tracking

- [ ] Agregar Google Tag Manager o GA4.
- [ ] Agregar Meta Pixel.
- [ ] Agregar LinkedIn Insight si se usará LinkedIn Ads.
- [ ] Validar UTMs desde campañas.
- [ ] Registrar eventos de WhatsApp, PDF y lead.

## QA mobile

- [ ] iPhone Safari.
- [ ] Android Chrome.
- [ ] Desktop Chrome.
- [ ] Lighthouse mobile.
- [ ] Lighthouse desktop.

## Después de publicar

- [ ] Medir tasa de clic a WhatsApp.
- [ ] Medir descargas de PDF.
- [ ] Medir leads guardados/enviados.
- [ ] Revisar calidad de conversaciones.
- [ ] Pausar campañas si no hay respuesta comercial en menos de 10 minutos hábiles.
