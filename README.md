# NearTec Web 2026

Sitio Next.js 14 para NearTec, preparado para Vercel.

## Actualización aplicada

- Home reestructurada para venta, diagnóstico y conversión.
- Blog actualizado con artículos 2026 y fuentes externas.
- Nueva ruta `/diagnostico` para campañas, WhatsApp y Meta Business.
- SEO técnico: metadata, Open Graph, Twitter cards, sitemap y robots generados por Next.js.
- Navegación depurada para evitar saturación en desktop y móvil.
- Cotizador conectado a WhatsApp con resumen de necesidad.
- Contacto actualizado con datos oficiales NearTec/CompuNegocio.
- Mejoras responsive para evitar recortes en móvil y navegador.
- Tablas, mapas y gráficas con animaciones ligeras y legibles.

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Rutas clave

- `/` Home comercial
- `/soluciones` Arquitectura de soluciones
- `/automatizacion` Automatización comercial
- `/compunegocio` CompuNegocio / CN7
- `/infraestructura` Hosting, nube, correo y respaldo
- `/diseno-web` Diseño web y conversión
- `/blog` Artículos actuales con fuentes
- `/diagnostico` Diagnóstico/cotizador
- `/contacto` Datos de contacto
