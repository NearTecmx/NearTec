# Investigación externa aplicada: competencia, SEO, Lighthouse y fiscal

## Competidores observados

### Facturama

Fortalezas visibles:

- API para facturación electrónica.
- Sandbox / ambiente de pruebas.
- Descarga PDF/XML.
- Plan API anual visible.
- Folios API por volumen.

Aplicación en NearTec/iTimbre:

- Mostrar ruta API / integración como caso de uso claro.
- Separar cotizador de empresa final y ruta para desarrolladores/distribuidores.
- Evitar que la percepción sea “página dispersa”; usar narrativa de ecosistema.

Fuente: https://facturama.mx/api-facturacion-electronica

### Factura.com

Fortalezas visibles:

- Landing directa de facturación electrónica.
- API explicada como conexión entre aplicaciones.
- CFDI 4.0, Carta Porte 3.1, nómina, complementos y reportes.

Aplicación:

- iTimbre debe usar lenguaje por solución: CFDI, API, Carta Porte, nómina, complementos.
- NearTec debe conectar la necesidad fiscal con operación, no vender fiscal aislado.

Fuente: https://factura.com/ y https://factura.com/api

### Alegra

Fortalezas visibles:

- Promesa simple: facturación en minutos, nube, soporte, actualizaciones.
- Planes desde precio bajo.
- Mensaje mobile/cloud y WhatsApp/IA.

Aplicación:

- No competir por precio bajo.
- Diferenciar por integración local, soporte, POS, nube, iTimbre y acompañamiento.
- Enfatizar “sistema conectado” más que “software suelto”.

Fuente: https://www.alegra.com/mexico/facturacion-electronica/

### POS y suites

Bloque competitivo: eleventa, Systienda, CONTPAQi, Odoo, Aspel/Siigo, Shopify, Zoho, HubSpot, Mailchimp.

Aplicación:

- Paquetes por dolor:
  - web que cotiza,
  - CRM + WhatsApp,
  - POS + facturación,
  - nube + soporte,
  - distribuidor iTimbre.

## Fuentes fiscales oficiales

### PAC

El SAT define PAC como persona moral autorizada para generar/procesar/validar/timbrar CFDI y enviar copia de CFDI validados a la autoridad.

Fuente: https://wwwmat.sat.gob.mx/consulta/76969/proveedores-autorizados-de-certificacion-%28pac%C2%B4s%29-

### Carta Porte

El SAT mantiene información oficial sobre Complemento Carta Porte; desde el 17 de julio de 2024 se usa CFDI 4.0 con versión 3.1 del complemento Carta Porte.

Fuente: https://wwwmat.sat.gob.mx/consultas/68823/complemento-carta-porte-

## Reglas de comunicación aplicadas

- No prometer “cero multas”.
- No prometer cumplimiento garantizado.
- No usar claim de PAC como gancho publicitario sin confirmación legal/dirección.
- Sí hablar de integración, trazabilidad, reducción de fricción operativa, soporte y acompañamiento.
