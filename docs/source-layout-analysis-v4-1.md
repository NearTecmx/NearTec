# Análisis aplicado V4.1

Referencias visuales y de código revisadas:

- Layout blanco/verde tipo SaaS tecnológico: navegación clara, hero con dashboard, tarjetas elevadas, métricas y separación por bloques.
- Consultores remotos: enfoque empresarial, servicios TI/nube, CTA de contacto y jerarquía de oferta clara.
- Qualisys: producto/infraestructura, contacto visible, estructura B2B, soporte y confianza.

Decisiones aplicadas:

- Se mantiene paleta NearTec, pero no predomina negro.
- Se agrega fondo técnico con grid, escaneo y panels flotantes sin depender de assets finales.
- Se separan secciones con fondos, bordes y cards elevadas.
- Se mejora tipografía con Inter + Space Grotesk.
- Se reduce texto tipo presentación y se prioriza copy dirigido a leads.
