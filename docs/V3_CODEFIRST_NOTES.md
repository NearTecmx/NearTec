# NearTec Sistema · CodeFirst Notes

Esta versión corrige la dirección estratégica: no concentra todo en una sola página. La home funciona como puerta de autoridad y cada oferta tiene ruta propia.

## Rutas

- `/` Home oficial NearTec
- `/landing/` Landing publicitaria BOFU
- `/diagnostico/` Diagnóstico corto
- `/cotizador/` Cotizador completo
- `/compunegocio/` Oferta POS / estaciones / timbres
- `/cn7/` Nube / respaldo / continuidad
- `/crm/` CRM / automatización / WhatsApp / scoring
- `/web/` Web comercial / UX / SEO / pauta
- `/soporte/` Soporte y SLA
- `/casos/` Casos y evidencia pendiente de assets
- `/recursos/` SEO / FAQs / contenido
- `/contacto/` Formulario y datos de contacto

## Pendientes intencionales

- Assets finales: mockups, videos, capturas y VFX no incluidos todavía.
- Legal final: aviso de privacidad debe revisarse.
- CRM real: requiere `NEARTEC_LEAD_WEBHOOK_URL`.
